Cloud Computing

Conceptos Clave:

  • SaaS: Software as a Service. Aplicaciones listas para usar alojadas en la nube.
  • PaaS: Platform as a Service. Entorno de desarrollo y despliegue en la nube.
  • IaaS: Infrastructure as a Service. Recursos informáticos virtualizados (servidores, redes).
  • Virtualización: Creación de versiones virtuales de recursos tecnológicos físicos.
  • Docker: Plataforma para desarrollar, enviar y ejecutar aplicaciones en contenedores ligeros.
